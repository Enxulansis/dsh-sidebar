# 发布检查

本项目仅通过GitHub发布Windows预览候选。第三方运行时插件不分发、不适配、不维护。

1. 确认README、安装指南、验证边界和上游署名准确，更新Release说明。
2. 运行 `pnpm install --frozen-lockfile`、`pnpm run check` 和 `pnpm run package`。
3. 检查源码、包内容、许可、敏感信息和哈希。不得包含私人home、会话、日志、测试驱动或凭据。
4. 将VSIX及配套安装材料作为Pre-release附件；源码、标签和附件必须对应同一已检查快照。
5. 发布后核对远端提交、可见性、预发布标记及附件哈希。

不要从开发工作目录强推已有分支，也不要把工作目录或依赖目录整体作为发行包。
